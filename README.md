# Lanternfold Run

A cozy endless runner for phone browsers. Bramble, a moss-green fox-like critter with a leaf on its head, carries a lantern across floating islands in the sky. Tap to jump, swipe down to slide, hold in the air to glide. All art and audio are generated by code; there are no external assets, no build step and no CDN.

> Status: **Stage 1 of 3** (core playable loop). Biomes, power-ups, companions, sound, installable/offline mode and the rest arrive in Stages 2 and 3.

## Play locally

ES modules need a web server (opening `index.html` from disk will not work):

```bash
python3 -m http.server 8000
# then open http://localhost:8000
```

To try it on your phone, put phone and computer on the same Wi-Fi and open `http://<your-computer-ip>:8000`.

## Controls

| Action | Touch | Keyboard |
|---|---|---|
| Jump | tap | Space / Up / W |
| Glide | hold while falling | hold the jump key |
| Slide | swipe down | Down / S |
| Pause | pause button | P / Esc |

Add `?debug` to the URL for an FPS / entity-count overlay.

## Tests

```bash
node tests/validate.mjs        # proves every level chunk is beatable (solver)
node tests/bot.mjs 8 3000      # autopilot plays 8 seeds x 3000 m on the real engine
python3 tests/e2e.py           # headless Chrome (Playwright): controls, save, pause, restart...
```

## Project layout

- `src/core/` loop, input, storage/save, RNG, quality monitor, haptics
- `src/game/` physics, level solver, chunk generator, world, tutorial, progress, juice
- `src/render/` canvas drawing (backdrop, terrain, Bramble, HUD, particles)
- `src/data/` all tunable numbers, level chunks, strings, biomes
- `src/ui/` title / pause / game-over screens
