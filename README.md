# Emberwing Run

*(working title: the final name is still to be decided)*

A dark-fantasy endless runner for phone browsers. You are **Cinder**, a Smaug-style red dragon with a gem-studded golden belly, fleeing the ashfall across broken islands in a burning sky. Tap to leap, swipe down to dive under iron traps, hold in the air to spread your wings and glide. All art and audio are generated by code: there are no external assets, no build step and no CDN.

> Status: **Stage 2 of 3** (biomes, power-ups, war beasts, forge, quests, daily run, sound). Achievements, cosmetics, stats, full settings, accessibility options, installable/offline mode (PWA), icons and the final QA pass arrive in Stage 3.

## Play locally

ES modules need a web server (opening `index.html` from disk will not work):

```bash
python3 -m http.server 8000
# then open http://localhost:8000
```

To try it on your phone, put phone and computer on the same Wi-Fi and open `http://<your-computer-ip>:8000`.

## Controls

| Action | Touch | Keyboard |
|---|---|---|
| Leap | tap (hold longer = higher) | Space / Up / W |
| Glide | tap again / hold while falling | hold the jump key |
| Dive (slide) | swipe down | Down / S |
| Pause | pause button | P / Esc |

## What is in Stage 2

- **Five biomes**, 400 m each, looping: Ashen Highlands, Ruined Keep, Emberdeep Caverns, Stormspire Peaks, Obsidian Lava Lake. Each has its own sky, parallax layers, weather, hazards, music and a stone gateway at the border.
- **Hazards and zones**: hanging iron portcullis traps (dive under them), spiked magma crawlers (leap), falling cinders, gaps (glide), steam vents that blast you skyward, plus speed zones (ash drifts, gales, fog).
- **Five power-ups**: Gold Magnet, Wing Gust, Inferno Dash, Firestorm, Scale Shield.
- **War Beasts**: nine companions with passive effects, unlocked by flying (not by paying).
- **The Forge**: five permanent upgrades bought with embers.
- **Quests**: three daily quests plus a weekly one, and a **Daily Run** (same course for everybody that day, with a streak).
- **Dragon eggs** (mystery chests) with a pity counter, a game-over card with quest progress and "% to next beast", a gentle take-a-break note after a long session.
- **Sound**: procedural music per biome that gets livelier with speed, SFX, separate music/SFX volume and mute.

## Tests

```bash
node tests/validate.mjs        # proves every level chunk is beatable (solver)
node tests/bot.mjs 8 3000      # autopilot plays 8 seeds x 3000 m on the real engine
python3 tests/e2e.py           # headless Chrome (Playwright): controls, save, pause, restart...
python3 tests/e2e2.py          # menus, forge, beasts, quests, daily run, eggs, audio, break note
```

Visual checks (write PNGs to `screenshots/`): `tests/gallery.py`, `tests/gallery2.py` (biomes, hazards), `tests/hero2.py` (the dragon in every pose; add `--low` for the lite version), `tests/sheets.py` (menu screens). Profiling helpers: `tests/fps.py`, `tests/fps2.py`, `tests/profile*.py`.

## Handy URL options

- `?debug` shows an FPS / entity-count overlay.
- `?startM=1000` starts a run at that distance in metres (jump straight to a biome; used by the tests).
- `window.__cozy` is a small debug handle used by the automated tests.

## Project layout

- `src/core/` loop, input, storage/save, RNG, clock, quality monitor, haptics
- `src/game/` physics, level solver, chunk generator, world, quests, daily run, chests, juice
- `src/render/` canvas drawing (backdrop, terrain, the dragon, companions, props, HUD, particles)
- `src/audio/` the Web Audio synth: music, SFX, volume buses
- `src/data/` all tunable numbers, level chunks, strings, biomes, power-ups, companions, upgrades, quests
- `src/ui/` title / pause / game-over screens and the menu sheets
